# Ripplemark Web App

Angular 19 standalone frontend for Ripplemark with PrimeNG styling, signals state, functional guards/interceptors, zoneless change detection, and lazy-loaded feature routes.

## Commands

- `npm start`
- `npm run build`
- `npm test`
- `npm run test:cov`
- `npm run lint`

## Features

- Dashboard
- Dependency Graph (D3 + websocket updates)
- Change Analysis (resource API)
- Service Registry
- Teams & Ownership
- Snapshot Comparison
